# DevOps Homework 3 – Install Dev Tools Script

## 📌 Опис проєкту

Цей проєкт містить Bash-скрипт `install_dev_tools.sh`, який автоматично встановлює основні інструменти для роботи DevOps-інженера:

- **Docker**
- **Docker Compose**
- **Python 3.9+**
- **Django (через pip)**

Скрипт перевіряє, чи встановлений кожен інструмент, і уникає повторного встановлення.

---

## ✅ Функціонал скрипта

✔ Оновлення системи (apt update & upgrade)  
✔ Перевірка наявності встановлених інструментів  
✔ Автоматичне встановлення Docker + додавання офіційного репозиторію  
✔ Встановлення Docker Compose  
✔ Встановлення Python 3 (якщо відсутній)  
✔ Встановлення Django через `pip3`  
✔ Виведення статусу кожного кроку
